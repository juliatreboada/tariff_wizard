# Reference material (local only)

This folder holds **private** tariff sheet references: official FIG PDFs, federation templates, filled examples, screenshots, etc.

Files here are **not** committed to git (see `.gitignore`). Only this template file is tracked.

## Where to put your files

**Stay in this folder** — the same place as this README. You do **not** need another path.

```text
reference/
  README.example.md    ← tracked (this file)
  tariff_example.pdf   ← your file (gitignored)
  BASE.xls             ← your file (gitignored)
```

If `tariff_example.pdf` and `BASE.xls` are already here, you are set.
